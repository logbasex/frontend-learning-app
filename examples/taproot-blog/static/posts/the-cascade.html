The cascade is the only CSS thing that matters

By Bob — 2026-04-15 — 6 min read

If you understand origin, specificity, and source order, you understand CSS.

Origin is where the rule came from — browser default, user, or author. Author rules win, with one exception: a !important declaration in user CSS beats author CSS.

Specificity is a four-tuple: inline styles, ID selectors, class/attribute/pseudo-class selectors, type/pseudo-element selectors. Compute each rule's tuple, compare component-wise, the higher tuple wins.

/* Specificity (0,1,0) — class only */
.button { color: blue; }

/* Specificity (1,0,0) — id wins */
#submit { color: red; }

Source order is the tiebreaker. When two rules have the same specificity, the one that appears later in the stylesheet wins.
